# تقرير الاختبار والتدقيق — شمال AI

**التاريخ:** 12 سبتمبر 2026 · **الرابط الحي:** https://shamal-ai.vercel.app

## 1) اختبار الخصائص

### أ. محرك الرحلة وقاعدة المعرفة (آلي — `npm test`)
30 اختباراً ناجحاً: سلامة القاعدة (جهات، روابط، مصادر، تاريخ تحقق، لا دورات في التبعيات)، مطابقة 18 عبارة باللهجة إلى سيناريوهاتها، ترتيب الخدمات حسب التبعيات، مؤشر الجاهزية بحالاته الثلاث، مسار «لو ما أقدر؟» الكامل (عائق عقد الإيجار → إيجار → العودة)، إكمال الخطوات وانتهاء الرحلة.

**خلل أُصلح:** كانت عبارة «أبي أسجل علامة تجارية لمشروعي» تُفهم كـ«بدء مشروع». صار وزن الكلمات المفتاحية بحسب طولها فتتفوق العبارات الأكثر تحديداً.

### ب. واجهات API على الرابط الحي
| المسار | النتيجة |
|---|---|
| `GET /api/auth/me` مجهول | `configured:true, user:null` ✅ |
| تسجيل بكلمة مرور قصيرة / بريد مكرر / كلمة مرور خاطئة | رسائل خطأ عربية صحيحة ✅ |
| تسجيل → دخول → تعديل الاسم → خروج | ✅ (الأسماء العربية تُحفظ سليمة) |
| `/api/data/journeys` و `/notifications` بدون جلسة | 401 ✅ |
| إدراج / قراءة / حذف الرحلات والإشعارات | ✅ |
| مجموعة غير معروفة `/api/data/users` | 404 ✅ |
| `/api/understand` بنص فارغ / بنص غير مفهوم / بطلب مشروع | 400 / null / start-business ✅ |
| `/api/assist` بدون مزود نموذج | رسالة بديلة واضحة ✅ |

### ج. الواجهة (Chrome على الرابط الحي)
إنشاء حساب، كتابة الاحتياج بلوحة المفاتيح، فهم الطلب، بناء الرحلة، قائمة التحقق (عندي/ما عندي)، إكمال الخطوة (1 من 1 مكتمل)، المحادثة داخل الرحلة، البحث في الخدمات («جواز» → نتيجتان) والفلترة («المرور» → خدمتان)، المفضلة في المحادثات، تعليم الإشعارات كمقروءة، تعديل الاسم والمدينة والصفة، مفاتيح الإعدادات (تُحفظ)، الأسئلة الشائعة، تسجيل الخروج وإعادة التوجيه إلى الدخول. الإدخال الصوتي متاح في Chrome (`webkitSpeechRecognition`) ويحتاج مايكروفوناً فعلياً للتجربة اليدوية.

## 2) تدقيق معلومات الخدمات (23 خدمة مقابل الصفحات الرسمية)

**الأعمال (10 خدمات، ~95 ادعاء):** الغالبية مطابقة. تصحيحات طُبّقت: رابط بلدي العربي (كان 404)، مدة حجز الاسم التجاري (10 أيام عمل لا فوري) ورسومه (200/500 ريال) ورابط خدمته، مدة رخصة بلدي «1–10 أيام»، اشتراط السجل التجاري في إيجار للمنشآت فقط، مصدر ووصف التراخيص التخصصية (التزام 90 يوماً)، رابط خدمة زاتكا، خطوة اعتماد نموذج التأمينات، خطوة موافقة الأطراف في السجل التجاري.

**الأفراد (13 خدمة):** الغالبية مطابقة، بما فيها الأرقام الحساسة (300 ريال جواز 5 سنوات، 39.91 توصيل، 600/500 إقامة، 100 ريال استمارة، 230+150 مبايعة، 300 زيارة عائلية، 125 ريال/سنة إيجار سكني، 6–19 عاماً و180 يوماً للهوية). تصحيحات طُبّقت: حذف تفاصيل لا تنص عليها المصادر (رفع نتيجة الفحص الطبي إلكترونياً، «يوم واحد» للفحص الدوري، الرمز المختصر للعنوان الوطني، الرخصة الرقمية، «20 يوماً» في الضمان، «حديثة» للتقارير الطبية)، تصحيح مسار تجديد الإقامة في أبشر وصياغة رسومها ورسوم رخصة القيادة، إضافة شرط 180 يوماً لتجديد الاستمارة، رابط منصة التأشيرات، وإضافة مصادر أبشر وواس الداعمة.

**بنود لم تنص عليها الصفحات الرسمية (تُركت بصياغة حذرة أو حُذفت):** المقابل المالي للمرافقين (مصدره قرار 2017)، رسوم جواز 10 سنوات، رسوم/مدة التراخيص التخصصية، صورة العلامة وفئتها في SAIP، مدة تسجيل ضريبة القيمة المضافة، محتوى بطاقة خدمة وزارة الصحة (لا يُحمَّل آلياً).

## 3) الروابط
87 رابطاً في قاعدة المعرفة. كلها تفتح في المتصفح. صفحات my.gov.sa وejar.sa وأبشر ترفض أدوات الفحص الآلي (403/تحويل) وهذا طبيعي. الروابط المعطلة أُصلحت (بلدي، مصدر المركز السعودي للأعمال، منصة التأشيرات). رابط تسجيل العنوان الوطني يحيل إلى صفحة دخول النفاذ، وهو السلوك الرسمي.
